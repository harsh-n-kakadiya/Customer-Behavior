# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from
3,900 customer purchases across different product categories.

The objective of this project is to identify spending patterns, customer
segments, product preferences, subscription behavior, and other factors that
influence customer purchasing decisions.

The project follows an end-to-end Data Analytics workflow using:

- Python for Data Cleaning and Exploratory Data Analysis
- PostgreSQL for Business Analysis
- Power BI for Data Visualization and Dashboard Development

---

## 🎯 Business Problem

A retail company wants to better understand customer shopping behavior to
improve sales, customer satisfaction, customer engagement, and long-term
loyalty.

The analysis focuses on understanding purchasing patterns across:

- Customer demographics
- Product categories
- Discounts and promotions
- Subscription behavior
- Shipping preferences
- Customer purchase history
- Product ratings

The goal is to generate data-driven insights that can help improve marketing
strategies, product positioning, and customer retention.
